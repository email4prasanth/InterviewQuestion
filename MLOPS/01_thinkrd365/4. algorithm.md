- In ThinkRD365, we mainly used:
    - Random Forest Classifier
    - Logistic Regression
    - XGBoost Classifier

1. Why Random Forest Classifier, 
- It is an ensemble algorithm, Multiple Decision Trees , learns from random subsets of data, subsets, Final prediction is based on **Majority Voting**
    - HR/payroll data had many features like unusual bonus, abnormal overtime, incorrect tax, duplicate payments that Handles non-linear relationships well
    - Performs well on tabular enterprise data
    - Reduces overfitting compared to single decision trees
    - Provides feature importance
- Limitations
    - Large model size
    - Slower training compared to Logistic Regression

2. Why Logistic Regression
- It calculates probability using weighted input features, sigmoid function
- Sigmoid Function The model converts prediction into probability
- Simple and interpretable, HR teams can understand feature impact, Fast training,Good baseline model
- Limitations
    - Struggles with complex non-linear patterns
3. Why XGBoost Classifier
- XGBoost was our best-performing model
- Very high accuracy, Handles structured enterprise data well, Works well with imbalanced datasets

- XGBoost uses Boosting Technique each new tree corrects previous tree errors
