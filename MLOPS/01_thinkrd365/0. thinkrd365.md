# Summary
```sh
ThinkRD365 is an Azure-based HR and payroll platform where we implemented MLOps practices for payroll anomaly detection and employee attrition prediction. In ThinkRD365, we mainly used Random Forest, Logistic Regression, and XGBoost classifiers for payroll anomaly detection, employee attrition prediction, and tax validation risk detection. Logistic Regression was used as an interpretable baseline model, Random Forest handled non-linear enterprise HR patterns effectively, and XGBoost provided the best production performance due to its boosting capability and high accuracy on structured payroll datasets. I worked on ETL pipelines, MLflow experiment tracking, DagsHub collaboration, Model Registry, CI/CD automation, drift monitoring, retraining pipelines, and secure deployment using Azure services. The focus was building scalable, secure, and production-ready ML workflows for enterprise HR analytics.
```

## Business Problem
- Its primary business function is to accurately prepare employee tax details for government reporting and introduce intelligent automation into HR and payroll operations.
- Use case
    - Payroll anomaly detection
    - Employee attrition prediction
    - Tax validation checks
    - Payroll forecasting
    - HR analytics
- The objective was:
    - Reduce manual verification effort

### MLOps Implementation
1. Data Pipeline - used Python ETL pipelines running on Azure VMs.

#### Feature Engineering
- It is required to understand the available data, know the business logic, create ml pipeline and prod thinking. 
- Feature engineering is the process of converting raw HR and payroll data into meaningful input variables that improve model prediction accuracy.
    - Payroll Anomaly Detection
    - Employee Attrition Prediction
    - Tax Validation Risk Detection
- End-to-End Feature Engineering Flow
```sh
Raw HR/Payroll Data # PostgreSQL databases, Historical payroll tables
          ↓
Data Cleaning # focus on Missing values, Null records, Duplicate records, Invalid tax entries
          ↓
Data Transformation # converted raw data into ML-friendly format using Scikit-learn (categorical data into numerical)
          ↓
Feature Engineering # based on attrition, anomaly, tax risk
          ↓
Feature Validation
          ↓
Training Dataset
          ↓
ML Model
```
