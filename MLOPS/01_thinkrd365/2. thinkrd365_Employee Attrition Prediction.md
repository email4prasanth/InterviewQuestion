## Business Objective
- Predict whether employee may resign.
- Classification Model
- Input Features
| Input Feature         | Description               |
| --------------------- | ------------------------- |
| employee_tenure       | Years in organization     |
| salary_growth_rate    | Salary increment history  |
| attendance_percentage | Attendance consistency    |
| leave_frequency       | Leave usage pattern       |
| overtime_hours        | Extra work hours          |
| performance_rating    | Employee rating           |
| promotion_count       | Number of promotions      |
| manager_change_count  | Reporting manager changes |
| training_completion   | Training participation    |
| department            | Employee department       |
| work_location         | Office location           |
| employee_age          | Employee age              |
- Output
```sh
0 = Likely to Stay
1 = Likely to Leave
```
- Algorithms Used
    - Logistic Regression
    - Random Forest Classifier
    - XGBoost Classifier
- Logistic Regression Hyperparameters
| Hyperparameter | Purpose                 |
| -------------- | ----------------------- |
| C              | Regularization strength |
| penalty        | L1/L2 regularization    |
| solver         | Optimization algorithm  |

- Random Forest Classifier Hyperparameters
| Hyperparameter    | Purpose                  |
| ----------------- | ------------------------ |
| n_estimators      | Number of trees          |
| max_depth         | Tree depth               |
| min_samples_split | Minimum split size       |
| min_samples_leaf  | Minimum samples per leaf |

- XGBoost Classifier Hyperparameters
| Hyperparameter | Purpose                |
| -------------- | ---------------------- |
| learning_rate  | Boosting speed         |
| max_depth      | Tree depth             |
| n_estimators   | Number of trees        |
| gamma          | Split regularization   |
| subsample      | Training data sampling |
- Business Usage: HR team uses prediction scores for:
    - Employee engagement
    - Retention planning
    - Workforce management
