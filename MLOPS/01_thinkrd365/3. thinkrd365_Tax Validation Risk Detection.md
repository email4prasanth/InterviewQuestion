## Business Objective
- Identify incorrect or risky tax calculations before government submission.
- Classification Model
- Input Features
| Input Feature        | Description                                |
| -------------------- | ------------------------------------------ |
| employee_salary      | Salary amount                              |
| declared_tax         | Submitted tax amount                       |
| expected_tax         | System-calculated tax                      |
| tax_difference       | Difference between expected and actual tax |
| country_tax_rules    | Country-specific rules                     |
| employee_tax_slab    | Tax bracket                                |
| bonus_amount         | Additional compensation                    |
| deductions_claimed   | Claimed deductions                         |
| payroll_frequency    | Payroll cycle                              |
| previous_tax_history | Historical tax records                     |
- Output
```sh
0 = Low Tax Risk
1 = High Tax Risk
```
- Algorithms Used
    -   Random Forest Classifier
    -   XGBoost Classifier
- Random Forest Hyperparameters Used
| Hyperparameter    | Purpose                  |
| ----------------- | ------------------------ |
| n_estimators      | Number of trees          |
| max_depth         | Tree depth               |
| min_samples_split | Minimum split size       |
| min_samples_leaf  | Minimum samples per leaf |
- XGBoost Hyperparameters Used
| Hyperparameter   | Purpose                   |
| ---------------- | ------------------------- |
| learning_rate    | Learning speed            |
| max_depth        | Tree complexity           |
| n_estimators     | Number of boosting rounds |
| subsample        | Data sampling ratio       |
| colsample_bytree | Feature sampling ratio    |
- Performance Metrics Precision, Recall, F1-score
- Business Usage: Compliance and finance teams use this to:
Prevent incorrect tax filing
Avoid penalties
Ensure compliance
