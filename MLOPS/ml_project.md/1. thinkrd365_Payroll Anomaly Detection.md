## Business Objective
- Detect abnormal payroll transactions before salary processing or tax filing.
- Classification Model
- Input Features

| Input Feature          | Description                   |
| ---------------------- | ----------------------------- |
| employee_salary        | Current employee salary       |
| avg_department_salary  | Average salary in department  |
| bonus_amount           | Bonus paid                    |
| overtime_hours         | Extra working hours           |
| overtime_payment       | Overtime compensation         |
| tax_deduction          | Tax deducted                  |
| leave_deduction        | Salary deduction due to leave |
| previous_salary        | Previous payroll amount       |
| salary_growth_rate     | Salary increment trend        |
| payroll_frequency      | Payroll cycle consistency     |
| duplicate_payment_flag | Duplicate payment indicator   |
| employee_grade         | Employee level                |
| country                | Employee location             |
- Output
```sh
0 = Normal Payroll
1 = Payroll Anomaly
```
- Algorithms Used
    -   Random Forest Classifier
    -   XGBoost Classifier
- Random Forest Hyperparameters Used
| Hyperparameter    | Purpose                  |
| ----------------- | ------------------------ |
| n_estimators      | Number of trees          |
| max_depth         | Tree depth               |
| min_samples_split | Minimum split size       |
| min_samples_leaf  | Minimum samples per leaf |
- XGBoost Hyperparameters Used
| Hyperparameter   | Purpose                   |
| ---------------- | ------------------------- |
| learning_rate    | Learning speed            |
| max_depth        | Tree complexity           |
| n_estimators     | Number of boosting rounds |
| subsample        | Data sampling ratio       |
| colsample_bytree | Feature sampling ratio    |
- Performance Metrics Precision, Recall, F1-score, ROC-AUC
- Business Usage:  Finance team reviews flagged payroll records before processing salaries.
